# Folio — Writers Publishing Platform

Folio is a warm, modern publishing place for writers and curious readers. It includes a responsive React client, a lightweight Express API, a personal reading shelf, discovery/search, author workspace, and an in-app publishing composer.

## Run locally

```bash
npm install
npm start                 # React client
npm run server            # Express API on :5000
```

The visual language follows `design-system.md`: soft lavender gradients, white rounded cards, geometric typography, gentle shadows, and a dark floating navigation bar.
