# Design System — Clean Minimal Course App

The Folio UI uses a soft, minimal purple-toned language adapted from this system: rounded cards, generous whitespace, subtle gradients, and a dark floating nav. The full reference remains available in the project design documentation.

Core tokens: `#6C5CE7` primary purple, `#4A3AFF` deep indigo, `#F6F5FA` off-white, `#1A1A1E` ink, `#8A8A93` secondary text, and `#ECEAF5` dividers. Cards use 24–28px radii and soft `0 8px 24px rgba(0,0,0,.06)` shadows.
